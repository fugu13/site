## What the user notices

- Opening any post puts the post's own name first in the tab, so several open tabs from the site are distinguishable at a glance; the author's name after the middot identifies the site when the tab is found later in history or bookmarks.
- A screen reader announces the same title when the page loads, so the post being read is named before its content begins.
- Search results and shared links display these same titles, so what a user clicks matches the tab they land in.
