# Heading Navigation

## Jumping between sections on the home page

A reader using a screen reader's heading-navigation shortcut steps from the page's main heading, "Russell Duhon's Software Development Writings", to the "Blog" section heading, then through each post's title in order — a strict, unbroken hierarchy with no level skipped. Post dates are not headings and are not announced as stops; they read as ordinary text under each title. The visible layout is unchanged: the "Blog" heading and post titles look the same size they always have.

## Jumping between sections on a post page

On a post page, the first heading announced is the post's own title, the page's main heading. From there, heading navigation steps through the post's section headings in order, one level below the title, with no skips. The "home" links above and below the post body are plain links, not headings — they appear in the links list, not the headings list, so heading navigation moves only through the post's real structure.
